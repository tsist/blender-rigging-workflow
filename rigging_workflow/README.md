# 角色绑定工作台 0.40.0

适用于 Windows / Blender 5.2.1 LTS。统一入口：3D 视图按 **N → 角色工作台**。已有角色选择骨架并点击“进入角色”；新角色直接从“准备与定位”开始。按准备、绑定、控制、面部、辅助动态、动画和维护阶段工作，日常、进阶、开发分层显示。

安装和完整操作见 [使用指南](USER-GUIDE.md)，AI 与公共命令调用见 [调用说明](AI-CALLS.md)，重定向细节继续见 [动画指南](RETARGET-USER-GUIDE.md)。历史 [重定向支持表](SUPPORT-MATRIX.md)只描述其具名验证范围，本次全面整顿的最终验收以交付包中的报告为准。

本包用于本机独立环境的安装交付；已验行为与限制见 [本轮验收说明](REVIEW-ACCEPTANCE.md)，精确交付快照由包外的描述文件和最终报告确定。未覆盖日常安装、未公开发布。私有模板、角色、定位图谱及外部 MMD 依赖不随代码包分发；本插件不下载或安装依赖。

保留已有工程、骨架、Action/Slot/NLA、权重、Key 及用户编辑。新建和重建输出独立副本；保存的文件不恢复内存中的提交批准。新增基础动作后须重新捕获辅助动态。原素材需要手工精修的问题、未支持的新能力与已暂停的 GLB/密集交换研究另行处理。
