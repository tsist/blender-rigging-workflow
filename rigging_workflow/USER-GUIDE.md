# 角色绑定工作台使用指南

## 安装与开始

使用交付目录的 legacy add-on ZIP，在 Blender 偏好设置中选择“从磁盘安装”，再启用“角色绑定工作台”。先在独立配置和工程副本中使用，保留旧版本回退包与原工程。制作插件和随文件便携面板共享操作名称，不同时启用。

3D 视图按 N，打开“角色工作台”。已有角色先选择骨架并点击“进入角色”，确认名称；新角色直接从准备与定位开始。工作台同步骨架类目标，保留来源骨架和网格编辑器的目标。“自动”阶段依据已有角色及本次会话显示入口，也可直接选择阶段。活动对象属于另一角色时先重新确认。

日常显示主要操作；进阶显示完整制作参数和细分工具；开发另外显示诊断和模板审查。旧工程无需因侧栏变化重建骨架。

## 准备与定位

新场景先选择本机私有定位图谱 `.blend`，点击“载入独立图谱”，明确目标中立网格，再点击“开始定位”。图谱库与原角色保持，工作区使用独立副本。进阶可直接指定场景中的完整参考、中立图谱及目标。

估计并检查身体、手和面部标记，按角色调整，再拟合完整参考骨。局部同步手调点不会解除其它标记造成的拟合失效；标记变化后须重新拟合。模板生成库与定位图谱不能互换。输入须已有可用拓扑及明确中立框架，造型或服装合身问题先回模型制作。

## 绑定与蒙皮

进入绑定阶段，先在上方选择模块及本机模板库并准备配置，再捕获本角色明确网格名单。已有绑定默认在独立副本上新建 C94，原骨架和旧动画保留。旧骨控动画、约束和驱动不直接迁移到新控制图。

生成角色后，给身体指定闭合代理，启动体积任务。完整角色入口使用本配置的身体形变骨范围；需要逐骨指定时使用进阶中的单代理工具。查看进度，成功后应用候选；多区域需求使用进阶中的多域蒙皮。服装可从本角色已应用的身体候选转移权重，刚性附件须明确指定骨。全部输入真实绑定后才能提交完整角色。取消会等待本次后台任务释放并清理本次自有数据。

局部重算、刷权重、权重策略、部件派生和姿态修正在进阶中。诊断或数值通过不能替代对实际姿态和变形的观察，原素材需手工精修的问题另列。

## 日常控制与面部

角色控制提供集合显隐、选择、原生模式和基础关键帧。保持当前姿态时使用 IK/FK 匹配按钮。单改属性可能改变姿态，记录只写当前帧，不自动补上一帧或烘焙。模式受已有动作或驱动控制时，切换可能拒绝并恢复原姿态，先处理该控制来源。

面部日常入口选择明确控制组，调整口型轴、滑杆、显隐和记录。多个控制组不会被猜选。进阶提供骨控/Key 模式、姿态库、骨姿采样为独立 Key、显式映射和 Key 修订。中立记录、手工 Key 身份和控制组须匹配，改名使用明确重绑流程。结束预览恢复本次显隐，提交仍严格核对源与草稿。

便携面板只包含角色控制和日常面部核心。在信任工程后，于 Text Editor 手动运行对应 Text；它不自动执行、安装插件或修改全局自动运行设置，不嵌入定位、蒙皮、作者工具或实时物理。

## 辅助动态

胸臀弹性与发束/裙摆分别管理。先安装或读取明确组，选择预设并应用参数，设置帧域并捕获基础动作，再预览和烘焙新原生 Action。原基础动作保留。参数或基础动作改变后重新捕获，旧片段不能代表新结果。

临时预览保存在内存中。保存前烘焙；停止预览恢复原轨道或本次显隐。进阶可修改求解参数、采样预算、冻结和重置。技术预设未替角色完成材料或美术标定，须检查实际动态、碰撞及必要中间帧。

## 动画重定向

选择 FBX/BVH、MMD 或通用映射来源，明确 Action/Slot、帧率与映射，生成独立候选，预览后使用“正式使用与撤回”。长动作及同来源批量使用进阶后台队列。稀疏预览不能正式使用，额外接触修正仍逐问题确认。保存或换文件会停止临时预览；遇外部改动保留当前工作并生成恢复信息。

MMD 文件导入和可选镜头需要已安装的外部依赖及明确路径。插件不下载依赖，既有原生 Action 播放不要求启用 MMD Tools。通用队列明确选择 Text、路径或 Profile 面板来源，避免混用残留表单。

来源支持、普通 FK 限制、MMD 表情/眼控、足部复核及可选镜头详见 RETARGET-USER-GUIDE.md、SUPPORT-MATRIX.md。旧文档所称“角色绑定/面部/动画重定向侧栏”在本版对应工作台中的同名制作阶段。

## 保存、交接与回退

以新文件名保存工程副本，保留私有模板、贴图、缓存和报告依赖。重开后核对角色、Action/Slot/NLA、关键姿态及面部/动态消费。文件不恢复内存会话中的复核、提交或逐问题批准权。

停用本版后用交付的旧版本 ZIP 或安装备份回退，只使用旧版本能理解的数据。显式迁移创建的新配置保持独立，原工程和配置留作恢复入口。不用旧运行时覆盖正在编辑的工程，不把 Undo 当文件备份。
