## 0.40.1 Blender 5.3 兼容

从 ZIP 安装后另启 Blender，检查插件注册和工作台“进入角色”操作。使用自行生成的单骨、带权立方体与两帧骨骼关键帧，另存并重开，核对角色选择、Armature 修改器、姿态和求值顶点。用同一试件在禁用脚本自动执行时审计并求值原生受限表达式，检查更改源文件指纹和超出受限范围的表达式被拒绝。测试分别使用 Windows Blender 5.2.1 LTS（`9e2066aef7ef`）与 5.3.0（`02f0899d78e3`）。下节的完整角色与重定向验收仍对应 5.2.1。
