# 模板与输入契约

完整新角色流程使用既定C94架构与授权的中文人形模板。模板文件与定位图谱不随开源分发；需由操作者显式提供并确认来源。不要把原工作站的路径或SHA当公共可用资产。

模板须保完整身体、四肢、手部控制／机制／形变、约束／driver、自定义属性和控件依赖。当前首模板Object/Data均为“千早爱音-素体骨架”；同名不能代替内容身份验证。其他结构只有经过相应适配和实际验证才可采用，不用Snow、简化骨数或新Rigify替换固定C94流程。

面部、发裙、附属链按角色配置；胸臀／独立趾可关闭，主骨盆／髋与基本四肢机制保留，按依赖裁剪并将必要权重归主骨。中文语义命名保IK/FK、.L/.R。

输入应具可用拓扑、明确单位／轴向和中立姿态、可分辨部件与合身服装；模型造型／几何问题回建模，不扩成绑定中的自动角色重制。定位只提出坐标，固定拟合负责骨位／长度／方向，CPD表面误差下降不代表关节正确。

完全直臂的IK求解／切换不支持，应略屈；T/A姿态定位本身可用。已有非C94骨架明确走原架构维护或各自支持的FK／Profile路径，不伪装有C94全部能力。
